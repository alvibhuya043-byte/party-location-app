Party Location Manager — Mobile Web App

ফিচার:
- Name
- পার্টি কোড
- মোবাইল নাম্বার
- লোকেশন ও Google Maps লিংক
- বর্তমান GPS লোকেশন নেওয়া
- ছবি যোগ করা
- Add / Edit / Delete
- JSON Export / Import
- ফোনের ব্রাউজারে ডাটা localStorage-এ রাখা
- PWA manifest সহ Home Screen ইনস্টল করার চেষ্টা

ব্যবহার:
1. ZIP খুলে index.html চালান।
2. Chrome-এ ব্যবহার করুন।
3. Home Screen-এ বসাতে Chrome-এর menu > Add to Home screen ব্যবহার করতে পারেন।
4. JSON Export দিয়ে ব্যাকআপ রাখুন। অন্য ফোনে JSON Import করা যাবে।

নোট:
- ডাটা এই ব্রাউজারের storage-এ থাকে; ব্রাউজার data/cache মুছে দিলে হারাতে পারে। নিয়মিত JSON Export রাখুন।
- Google Maps-এর জন্য আলাদা API key লাগবে না; লোকেশন সার্চ লিংক ব্যবহার করা হয়েছে।
